# C - Урок 12:

## Пройдено
- Препроцессор - это программа, которая запускается до компилятора и обрабатывает строки, начинающиеся с #. Он подключает файлы, подставляет текст вместо имени (`#define`), включает/выключает куски кода по условию (`#if`, `#ifdef`).
- `#include <...>` - "ищи в системных папках", `#include "..."` - "ищи в текущей папке"
- `#define ИМЯ значение` создает макрос, скобки в макросе обязательны, так как препроцессор не вычисляет, а просто заменяет все `ИМЯ` на `значение`
- защита заголовка `#ifndef/#define/#endif` нужна для однократной подстановки содержимого файла
- `#ifdef DEBUG #endif` - условная компиляция - включить код только при отладке

## Код
```c
`main.c`
#include <stdio.h>
#include "utils.h"

int main() {
    printf("Минимум: %d\n", MIN(3, 7));
    printf("Куб: %d\n", cube(4));

    return 0;
}

`utils.c`
#include "utils.h"

int cube(int x) {
    return x * x * x;
}

`utils.h`
#ifndef UTILS_H
#define UTILS_H

#define MIN(a, b) ((a) < (b) ? (a) : (b))

int cube(int x);

#endif
```
