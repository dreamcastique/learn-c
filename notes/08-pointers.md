# C - Урок 08:

## Пройдено
- & оператор, который нужно подставить к переменной для вычисления ее адреса
- указатель это переменная, которая хранит адрес другой переменной, а тип нужен для корректной работы компилятора с адресами переменных
- p - значение в виде адреса, а *p - значение той переменной, на которую указывает адрес
- `arr[i]` = `*(arr + i)` - аналогичный вывод массива

## Код
```c
#include <stdio.h>

int main() {
    int a = 10;
    int b = 20;
    int temp;

    int *pa = &a;
    int *pb = &b;

    temp = *pa;
    *pa = *pb;
    *pb = temp;

    printf("a = %d, &a = %p, pa = %p\n", a, (void *)&a, (void *)pa);
    printf("b = %d, &b = %p, pb = %p\n", b, (void *)&b, (void *)pb);

    return 0;
}
```
