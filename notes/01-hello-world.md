# C - Урок 01: Hello, World!

## Пройдено
- #include <stdio.h> - дает нам право использовать printf
- `main()` - главная функция, точка входа, возвращает int
- Что такое компилятор
- {} - тело функции
- printf("...")
- `return 0;` - успешное завершение


## Код
```c
#include <stdio.h>

int main() {
        printf("Hello, World!\n");
        return 0;
    }
```
