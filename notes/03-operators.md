# C - Урок 03:

## Пройдено
- операторы арифметические (+-*/%), сравнения (== != > < >= <=), логические (&& || !) 
- остаток от деления
- целочисленное и дробное деление


## Код
```c
#include <stdio.h>

int main() {
    int year;

    printf("Введи год: ");
    scanf("%d", &year);

    printf("%d", ((year % 4 == 0) && (year % 100 != 0)) || (year % 400 == 0));

    return 0;
}
```

## Ошибки
- случайно писал = вместо ==
- забывал &
- забывал ;
