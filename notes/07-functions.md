# C - Урок 07:

## Пройдено
- функция - именованный блок кода, чтобы код не повторялся и лучше читался
- аргументы (что ты вводишь) и параметры (куда ты вводишь) функции
- тип void (ничего не возвращает/принимает)
- прототип функции писать до `main()`, чтобы компилятор знал о ее существовании заранее
- область видимости, локальные переменные видны только внутри своей функции или блока {}


## Код
```c
#include <stdio.h>

// Прототипы функций (объявления)
int sum(int a, int b);          // функция принимает два int, возвращает int
void print_hello(void);         // функция ничего не принимает, ничего не возвращает

int main(void) {
    // Вызываем функцию print_hello
    print_hello();

    // Вызываем функцию sum и сохраняем результат
    int result = sum(3, 5);
    printf("Сумма: %d\n", result);

    // Можно вызывать функцию прямо внутри printf
    printf("Сумма 10 и 20: %d\n", sum(10, 20));

    return 0;
}

// Реализация функции print_hello
// void означает, что функция не возвращает значение
// (void) означает, что функция не принимает аргументов
void print_hello(void) {
    printf("Привет, мир функций!\n");
}

// Реализация функции sum
// int a, int b — это параметры (входные данные)
// return возвращает результат вызывающему коду
int sum(int a, int b) {
    int result = a + b;
    return result;  // возвращаем сумму
}
```
